# AGENTS.md

Landing page do Ace — React + Vite + TypeScript.

## ui-sdk

Antes de usar o ui-sdk: siga a skill `ui-sdk` se estiver instalada, e leia `node_modules/@ui-sdk/react/docs/llms.txt`. Para montar um componente novo, busque também por título em `node_modules/@ui-sdk/react/docs/core.md` e leia o `rendering.md` ao lado dele.

## Build

```sh
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # tsc + vite build
```
